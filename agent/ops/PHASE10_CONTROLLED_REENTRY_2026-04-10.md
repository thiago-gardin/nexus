# Phase 10 Controlled Reentry Minimum

- Eligible edit cases: `entity.short_description` and `relation.validation_status` from published snapshots.
- Submission path: published snapshot edit -> structured proposal -> existing governance flow only.
- Explicitly out of scope: full reentry, arbitrary artifact editing, agent approve/reject, MCP complete, broad bidirectional sync.
- Rationale: keep reentry controlled, auditable, and non-sovereign while reusing the current governance runtime.
