# Phase 9 Proposal-from-Edit

- Supported case: entity `short_description` edits originating from a published snapshot on the human surface.
- The edit is converted into a structured proposal only; the live entity is not mutated until governance approval.
- Traceability is preserved through the published artifact path, the target object id, the object history link, and the proposal/decision bundle.
- Explicitly out of scope: full reentry, arbitrary artifact editing, agent approve/reject, and MCP complete.
