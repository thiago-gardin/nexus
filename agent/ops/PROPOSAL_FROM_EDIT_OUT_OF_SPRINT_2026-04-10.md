# Proposal-from-Edit Decision

Date: 2026-04-10

Decision: proposal-from-edit is intentionally out of scope for the Phase 3 operational materialization minimum sprint.

Reason: the current sprint goal is to make the treefolder publication more useful while keeping executable state authoritative. Introducing edit circulation would widen the regime beyond minimal publication and would require a separate circulation/reentry slice.

Operational effect:
- no proposal-from-edit route is introduced in this sprint;
- treefolder publication remains read-derived with structured proposals only in `tree/inbox/proposals/`;
- future edit-to-proposal circulation must be proposed as a separate slice.
